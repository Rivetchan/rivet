🌐 Rivet — Website Modern dengan TailwindCSS

**Rivet** adalah website modern yang dibangun dengan **HTML, CSS, JavaScript**, menggunakan **TailwindCSS**.
Website ini responsif, interaktif, dan cocok digunakan sebagai landing page, portofolio, atau halaman profil online.

Demo Online: [rivetchan.enno-nurwansyah-rasyidi.workers.dev](https://rivetchan.enno-nurwansyah-rasyidi.workers.dev/)

---

## ✨ Fitur Utama

- Desain modern dan responsif menggunakan TailwindCSS
- Interaktivitas UI dengan JavaScript
- Mudah dikustomisasi melalui Tailwind.config.js
- Siap di-deploy ke layanan hosting statis

---

## 🛠 Teknologi

- HTML, CSS, JavaScript
- TailwindCSS
- Node.js & NPM (untuk build tools)
- Cloudflare Workers / Static Hosting

---

## 📁 Struktur Project

```text
rivet/
├── assets/ # Gambar, font, dll
├── css/ # File CSS
├── js/ # File JavaScript
├── src/ # Source code utama
```
